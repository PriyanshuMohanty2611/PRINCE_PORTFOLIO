# Priyanshu Mohanty - AI/ML Engineer Portfolio

![Portfolio Preview](https://github.com/PriyanshuMohanty2611/PRINCE_PORTFOLIO/blob/main/public/favicon.png?raw=true)

A premium, interactive personal portfolio showcasing expertise in **Artificial Intelligence**, **Machine Learning**, **Computer Vision**, and **Full Stack Development**. This project features a high-performance particle network background, glassmorphic UI components, and a dedicated digital resume section.

---

## 🌟 Key Features

- **Plexus Network Background**: A dynamic, interactive particle network that responds to mouse movements, built with high-performance Canvas rendering.
- **Digital Interactive Resume**: A bespoke section mirroring a professional CV with categorized expertise in AI/ML, Experience, Education, and Achievements.
- **Glassmorphic Design**: Modern aesthetic using backdrop-blurs, subtle gradients, and sleek typography for a premium software engineer look.
- **Custom Loading Sequence**: Personal identifier "PM" and skills-focused marquee loading.
- **Responsive Layout**: Fully optimized for Desktop, Tablet, and Mobile viewing.

## 🛠️ Installation & Setup

To run this portfolio locally on your machine:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/PriyanshuMohanty2611/PRINCE_PORTFOLIO.git
   ```

2. **Navigate to the directory**:

   ```bash
   cd PRINCE_PORTFOLIO
   ```

3. **Install dependencies**:

   ```bash
   npm install
   ```

4. **Start the development server**:

   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
